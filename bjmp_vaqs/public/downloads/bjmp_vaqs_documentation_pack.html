Combined Process Flow and User Manual

This consolidated document serves as an internal reference for the ID & Queuing System Visitor Admission and Queuing System. It combines the process flow, module guide, role guidance, and user operating instructions into a single formal document for printing and distribution.

1. Click-by-Click Process Flow Summary

  1. Login: open the login page, enter username and password, then click Sign In.
  2. Prepare references: open Masterlist, choose Case, Court, or Dorm, click Add, enter details, then click Save.
  3. Add PDL: open PDL Management, click Add New, fill in PDL details, select dorm/case/court, add the five (5) authorized visitors provided by the PDL prior to or during commitment, review the entry, then click Save.
  4. Import PDL: click Import PDL, download the CSV template, fill in the file, choose the file, then click Import PDL.
  5. Add visitors to PDL: find the PDL row, click the visitor or import visitor button, add visitor details or upload the visitor CSV, then save.
  6. Register visitor: open Visitor Registration, select PDL, click Next, add visitor details, click Next, upload photo/documents, click Next, review, then submit.
  7. Review visitor: open Visitor Management, search the visitor, click View, edit details/files if needed, then save.
  8. Issue ID: open ID Issuance, select PDL, select visitor, click Issue ID, review the preview, then print PVC or export PDF.
  9. Queue admission: open Queue, scan QR, review details, click Put in Queue, confirm, then accept or reject the request.
  10. Time out visitor: find the inside visitor in the queue table and click Time Out.
  11. Reports: open Reports, choose report type, apply filters, arrange columns, then export Excel, PDF, or print.
  12. User governance: open Manage Users, select a user, assign role, tick permissions, then save.

3. Operational Rules

Critical Queue Rules: Each visitor may visit only once per day, only ten visitors may be inside at one time, and the queue board resets daily to current-day activity.
  • Action buttons are permission-controlled.
  • Super admin grants permission before a user can use a function.
  • Admission reports include time in, time out, and hours stayed.
  • ID issuance maintains issuance history for audit and reissue reference.

4. User Operating Guide

4.1 Staff

Staff are responsible for frontline work such as visitor handling, queue intake, and selected issuance operations according to granted permissions.

4.2 Admin

Admins supervise PDL, visitor, reporting, queue, and issuance operations. Their permissions are operational by default and may be extended by super admin.

4.3 Super Admin

Super admin controls platform governance, including users, roles, action permissions, and reset approvals.

5. Recommended Daily Sequence

  1. Open Dashboard and check the current operational summary.
  2. Open Masterlist and confirm case, court, and dorm references are correct.
  3. Open PDL Management, add new PDL records, or import PDL records if needed.
  4. For each PDL, click the visitor button and add or import the five (5) authorized visitors provided by the PDL prior to or during commitment.
  5. Open Visitor Registration, select PDL, click Next, add visitor details, click Next, upload files, review, and submit.
  6. Open ID Issuance, select PDL, select visitor, and issue or re-issue the visitor ID.
  7. Open Queue, scan the QR, click Put in Queue, then accept the visitor if capacity is available.
  8. Open Queue Monitor or Queue Board to monitor waiting and inside visitors.
  9. Click Time Out when a visitor leaves.
  10. Open Reports, choose filters, arrange fields, and export the needed report.
