Buttons to Remember

Quick user guide for the common buttons and actions found across the system
Purpose: This file helps users quickly understand what each button does before clicking it. It may be printed, saved, or shared as a quick desk reference.
Button Description
Add New Opens a form to create a new record.
Edit Allow modification of an existing record.
Delete Removes a record from the system.
Import PDL Upload multiple PDL records at once, only use a correctly formatted CSV file.
Import Visitors Uploads visitor records linked to a selected PDL, make sure the import is being done for the correct PDL record.
Back Go back to the last page visited.
Save Store a new record or updated information, review the form first, then click when all required fields are complete.
Cancel Stop the current action, use this if you do not want to continue with the pending action.
Load Visitors Load the data fetch from database to datatable.
Reset Reload the latest data on the page, use this when you want to see updated queue or record information.
Put in Queue Adds a verified visitor to the waiting queue, confirm that the correct visitor details are on screen first.
Queue Shortcut button used to send or prepare an eligible visitor for queue processing.
CSV Template Downloads the correct sample format before importing records into the system.
Guide Downloads or opens written instructions to help the user complete an import or process correctly.
Outline Template Downloads the outline-only import format used for alternative bulk encoding workflows.
Import Outline Uploads a prepared outline-based import file into the system.
Choose File Opens the device file picker so the user can attach a CSV, photo, or document for upload.
Upload Sends the selected file or document into the system after the user confirms it is the correct one.
Search Looks for matching records such as visitor names, PDL information, or queue entries.
Refresh Reloads the latest data on the current page, especially useful for queue and monitoring screens.
View Opens the full details, preview, or record contents for the selected visitor, document, or item.
Approve Accepts a pending request, special-case admission, or reset request and allows the process to continue.
Reject Declines a pending request or queue action when the visitor or user should not proceed.
Confirm Finalizes the current action after the user has reviewed the details shown in the modal or form.
Confirm & Continue Saves the current registration step and unlocks the next step in the workflow.
Start Registration Begins a new visitor registration flow for a selected or newly identified visitor.
Continue Registration Returns to an unfinished registration so the user can complete the remaining steps.
Submit Registration Submits the completed visitor registration after all details and documents have been reviewed.
Start Camera Turns on the camera so the user can capture a live visitor photo during registration.
Capture Takes the current camera image and prepares it for review before saving as the visitor photo.
Stop Turns off the active camera session or stops the current live image capture process.
Remove Deletes the selected uploaded file, preview, or temporary captured photo from the current form.
Review Document Opens the selected document preview first so the user can check if the uploaded file is correct and readable.
Confirm Safe Marks that the user reviewed the file and accepts responsibility for uploading the correct document.
Confirm Upload Uploads the currently selected document after the file has been reviewed and approved by the user.
Verified Shows that a visitor record or registration has already been completed and verified.
Visitors Opens the list of authorized visitors linked to the selected PDL record.
Load Visitors Loads visitor data from the database into the current table or management view.
Issue ID Creates a visitor ID card for the selected visitor and opens the preview/printing screen.
Re-Issue Creates a replacement ID for a visitor who already has one on record.
Print PVC Prints the visitor ID in PVC card format after the preview has been checked.
Export A4 PDF Exports the generated visitor ID or related card layout as an A4 PDF file.
Zoom + Increases the preview size so the user can inspect the generated ID card more closely.
Zoom - Decreases the preview size on the ID screen when the current zoom is too large.
Special Case Starts the controlled workflow for visitors who do not follow the regular queueing or ID path.
Time Out Marks that the visitor has already left the facility and completes the visit cycle in monitoring and reports.
Admin Monitor Opens the live admin queue-monitoring page for operational supervision.
Visitor Board Opens the public-facing queue board used to display waiting or admitted visitors.
Run Report Generates the selected report after filters such as source, date, dorm, or PDL are chosen.
Export Excel Downloads the current report as an Excel file for sorting, submission, or further encoding.
PDF Report Opens or downloads the active report in PDF format for printing or formal reporting.
Print Report Opens the current report in a print-friendly layout for paper output.
Save Permissions Applies the selected role and access matrix changes to the chosen user account.
Submit Reset Request Sends a password reset request to the administrator for account recovery processing.
Delete Today's Logs Deletes the current day’s activity logs, used only when audit cleanup is intentionally authorized.
Delete Selected Date Deletes log records for one selected date only.
Delete Date Range Deletes activity logs from a selected start date up to the chosen end date.
Close Closes the open modal, preview, or screen without applying any further action.
