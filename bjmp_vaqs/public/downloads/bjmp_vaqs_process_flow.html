Click-by-Click System Flow Guide

How to Use the System Step by Step

A friendly guide that tells users what to click, select, fill in, and save
How to read this guide: Follow each section in order. Each workflow shows the screen to open, the button to click, the details to encode, and the final action to save, print, approve, or export.

1. Start of Day Setup

Admin / Super Admin

Update Masterlist Records

Sidebar > Masterlist
  1. Click the Case, Court, or Dorm tab.
  2. Click Add Case, Add Court, or Add Dorm.
  3. Enter the required details such as case number, court name, dorm number, or dorm description.
  4. Click Save.
  5. Use the search box to confirm that the new record appears in the table.

2. PDL Record Preparation

Admin

Add a PDL Record Manually

Sidebar > PDL Management > Add New
  1. Click Add New.
  2. Fill in PDL identity details such as first name, middle name, last name, age, sex, and suffix if available.
  3. Select or enter the assigned Dorm.
  4. Add case details such as Case No., Case Type, and Court.
  5. Add the five (5) authorized visitors provided by the PDL prior to or during commitment.
  6. Encode each authorized visitor's available information, such as full name, relationship, address, and contact details.
  7. Upload the PDL photo if available.
  8. Review all details, then click Save.
Admin

Import PDL List

Sidebar > PDL Management > Import PDL
  1. Click CSV Template.
  2. Open the downloaded file and fill in the PDL rows.
  3. Save the completed file as CSV.
  4. Return to the import page and click Choose File.
  5. Select the completed CSV file.
  6. Click Import PDL.
  7. Wait for the success message, then return to PDL Management to review the imported records.
Admin

Import Visitors for One PDL

Sidebar > PDL Management > PDL row > Import Visitors button
  1. Find the PDL record in the table.
  2. Click the green Import Visitors button on that PDL row.
  3. Click CSV Template and fill in the visitor details.
  4. Save the completed CSV file.
  5. Click Choose File and select the completed visitor file.
  6. Click Import Visitors.
  7. The system will attach those visitors to the selected PDL only.

3. Visitor Registration

Staff / Admin

Register a Visitor

Sidebar > Visitor Registration
  1. Click Start Registration or open the first registration section if the form is already visible.
  2. Click or search the PDL field.
  3. Select the correct PDL from the list.
  4. Click Next to continue to visitor information.
  5. Enter visitor personal details such as first name, middle name, last name, age, sex, contact number, and address.
  6. Click Next to continue to requirements and emergency contact.
  7. Enter emergency contact details.
  8. Upload the visitor photo.
  9. Upload required documents such as birth certificate, marriage contract, cohabitation certificate, or other required files if applicable.
  10. Click Next to review the encoded information.
  11. Check the summary carefully. If something is wrong, click Back and correct it.
  12. Click Submit or Save Registration.
  13. Wait for the confirmation message before leaving the page.

4. Visitor Review and Management

Staff / Admin

Review or Update a Visitor

Sidebar > Visitor Management
  1. Use the search box to find the visitor by name, PDL, contact number, or status.
  2. Click the visitor row or the View button.
  3. Review visitor details, linked PDL, uploaded files, and current status.
  4. To update details, click Edit, change the needed fields, then click Save.
  5. To change a photo or document, open the update area, choose the new file, then click Upload or Save.
  6. To ban a visitor, click Ban, enter the violation and effective date, then click Confirm.
  7. To lift a ban, click Lift Ban, enter the reason for lifting, then click Confirm.

5. ID Issuance

Staff / Admin

Issue Visitor ID

Sidebar > ID Issuance
  1. Select the PDL from the PDL table.
  2. Wait for the authorized visitor list to load below.
  3. Find the visitor who needs an ID.
  4. Click the visitor row if the system requires selection before showing the action buttons.
  5. Click Issue ID.
  6. If the visitor already has an ID, click Re-Issue only when replacement is needed.
  7. Review the generated ID preview.
  8. Click Print PVC for card printing, or click PDF to export a copy.

6. Queue Admission

Staff / Admin

Put Visitor in Queue

Sidebar > Queue
  1. Scan the visitor QR code.
  2. Check the visitor details shown on screen.
  3. If the visitor is correct, click Put in Queue.
  4. If the visitor presented an ID, select the ID type and enter the ID number.
  5. If ID is not available and the visit is allowed, use the approved special case workflow.
  6. Click Confirm.
Admin

Accept or Reject Queue Request

Sidebar > Queue > Visitor Request Table
  1. Find the visitor in the request table.
  2. Click the green Accept button to let the visitor inside.
  3. If the visitor should not proceed, click the red Reject button.
  4. The system will block acceptance if there are already 10 visitors inside.
  5. After the visit, click Time Out to complete the admission.
Admin

Create Special Case Visitor

Sidebar > Queue > Special Case
  1. Click Special Case.
  2. Enter the visitor first name, middle name, last name, age, gender, and address.
  3. Search and select the related PDL.
  4. Enter ID type and ID number if available. If none, leave optional ID fields blank.
  5. Enter the reason for visit.
  6. Enter the approving officer or admin details and approval date.
  7. Click Save or Add to Queue.
  8. The special case record will be included in queue monitoring and reports.

7. Live Monitoring

Admin

Monitor Queue Activity

Sidebar > Queue Monitor
  1. Open Queue Monitor.
  2. Check the Waiting, Inside, Completed, and Average Wait counters.
  3. Review Visitors Currently Inside to see all visitors admitted today.
  4. Review Waiting Queue to know who is next.
  5. Use Recent Admissions and Live Activity Feed for quick checking.

8. Reports

Staff / Admin

Generate a Report

Sidebar > Reports
  1. Select the report type, such as Admissions, Registrations, ID Issuance, Banned Visitors, or Special Case Visits.
  2. Select the date coverage, such as Daily, Monthly, Yearly, or Custom Range.
  3. Use filters if needed: dorm, gender, PDL, ban status, violation, or date range.
  4. Click Show Report.
  5. Optional: open Choose columns, check the fields to include, drag fields to arrange them, and rename headers.
  6. Click Export Excel, PDF Report, or Print Report.

9. User Permission Management

Super Admin

Approve Users and Assign Permissions

Sidebar > Manage Users
  1. Open Manage Users.
  2. Review registered users and pending password reset requests.
  3. Select the user account.
  4. Choose the correct role, such as Staff, Admin, or Super Admin.
  5. In the permission matrix, check only the modules and actions the user is allowed to use.
  6. Click Save Permissions.
  7. Ask the user to log out and log in again if the permission change is not immediately visible.
