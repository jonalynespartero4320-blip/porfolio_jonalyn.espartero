High-Level Process Flow

  1. User signs in. The system validates account credentials and loads features allowed by role permissions.
  2. User opens a module. The sidebar groups workflows for Dashboard, Requests, Equipment, Supplies, Assignments, Operations, Reports, and Masterlists.
  3. User creates or updates records. Required fields are completed, duplicate checks and validation rules are applied, and changes are saved.
  4. System tracks operational status. Requests, inventory records, assignments, reports, uploads, and archives are maintained in their respective tables.
  5. Authorized users review and approve. Administrators or managers process request statuses, password reset requests, user roles, and permissions.
  6. Reports are generated. Users filter records and produce printable, PDF, or Excel outputs according to permission.
  7. Activity is audited. System actions are logged for monitoring and accountability.

Maintenance Notes

  • Update this documentation when new modules, fields, permissions, or approval rules are added.
  • Keep masterlists standardized to prevent duplicate dropdown values.
  • Review role permissions after organizational changes.
  • Archive inactive records for audit history instead of immediately deleting them.
