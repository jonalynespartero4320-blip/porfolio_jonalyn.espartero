1. System Overview

The IMS centralizes ICTD inventory records, requests, assignments, reports, archives, masterlists, and user access control. Features shown to each user depend on assigned role permissions.

AreaPurpose
DashboardView summary cards and operational statistics.
RequestCreate and monitor equipment or service requests.
Equipment and SuppliesRegister, update, import, archive, and review inventory records.
AssignAssign equipment to end users, upload PDFs, reassign items, and keep assignment history.
ReportsPrepare service, maintenance, transmittal, and general reports with export or print options.
MasterlistMaintain reusable dropdown values such as suppliers, departments, statuses, and related references.
AdminManage users, roles, permissions, reset requests, and activity logs.

2. Access and Login

Login

  1. Open the IMS web address in a browser.
  2. Enter your registered username or email and password.
  3. Select Login.
  4. After successful login, the system opens the page allowed for your role.

Register a New Account

  1. Open the registration page.
  2. Fill in the required account details.
  3. Create a secure password and confirm it.
  4. Select Create Account.
  5. Wait for account review or approval if your organization requires it.

Forgot Password or Reset Request

  1. From the login screen, select Forgot password?.
  2. Submit the requested account information.
  3. An administrator reviews the reset request.
  4. When approved, follow the provided reset instructions or temporary access procedure.
Security reminder: Do not share your password. Log out after using a shared computer.

3. Navigation

Sidebar

  1. Use the sidebar to open modules such as Dashboard, Request, Equipment, Supplies, Assign, Reports, and Masterlist.
  2. Select a main group to expand its child pages.
  3. Use the search box in the sidebar to quickly filter modules.
  4. Use the collapse button to switch between full sidebar and compact rail view.

4. Dashboard

  1. Open Main > Dashboard.
  2. Review cards, charts, or counters for quick status checking.
  3. Use dashboard shortcuts, if available, to jump to the related module.
  4. Refresh the page if you need the latest displayed statistics.

5. Request Modules

Request Module Overview

  1. Open Request > Request Modules.
  2. Review request categories such as Equipment and Service.
  3. Use the displayed actions to create a request, view status, or open archives.

Create an Equipment Request

  1. Open Request > Equipment > Request Equipment.
  2. Select the request option to add a new equipment request.
  3. Fill in requester details, department, equipment needed, quantity, purpose, and other required fields.
  4. Review all entered details.
  5. Select Save or Submit.
  6. Use the request status page to monitor approval, rejection, assignment, or completion.

Create a Service Request

  1. Open Request > Service > Request Service.
  2. Create a new service request.
  3. Enter the requester, department, service type, issue description, and priority or remarks if required.
  4. Submit the request.
  5. Check Request Status for pending, acknowledged, assigned, accomplished, rejected, or cancelled items.

Manage Request Status

  1. Open the correct Request Status page.
  2. Use filters such as All, Pending, Acknowledged, Assigned, Accomplished, Rejected, or Cancelled.
  3. Select an action such as acknowledge, assign, accomplish, reject, cancel, or archive, depending on permission.
  4. Provide required notes or reasons when prompted.
  5. Confirm the action.

Request Archives

  1. Open Request Archive under Equipment or Service.
  2. Search for archived requests by keyword.
  3. Use restore or permanent delete only when allowed and necessary.

6. Equipment and Supplies

Manage Equipment

  1. Open Equipment > Manage Equipment.
  2. Use the search box, table filters, or status filters to locate records.
  3. Select Add Equipment to open the batch entry form.
  4. Enter Batch Details, including supplier and date delivered.
  5. Fill in each equipment row, including control number, equipment type, brand/model, serial number, status, and related details.
  6. Select Add Another Equipment for additional rows.
  7. Select Save Batch to save all rows at once.
  8. Use View to inspect details, Edit to update a record, or Archive to move it out of the active list.

Import Equipment

  1. Open Equipment > Import data.
  2. Download or follow the required template format if provided.
  3. Prepare the import file with complete and valid columns.
  4. Upload the file.
  5. Review validation messages and correct errors if needed.
  6. Confirm the import.

Equipment Archive

  1. Open Equipment > Archive.
  2. Search archived equipment by keyword such as control number, serial number, or item name.
  3. Restore a record if it must return to the active list.
  4. Permanently delete only when the record should no longer be retained.

Manage Supplies

  1. Open Supplies > Manage Supplies.
  2. Select Add Supply.
  3. Enter supply code, item description, quantity, unit, supplier, status, and other required details.
  4. Select Add Another Supply if entering multiple supplies.
  5. Select Save Supply.
  6. Use view, edit, archive, import, and archive pages as needed.
Tip: Keep supplier, department, and status masterlists updated before encoding inventory. Clean masterlists reduce wrong dropdown selections.

7. Assignment Module

Create a New Assignment

  1. Open Assign > Manage Assign.
  2. Select New Assignment.
  3. Choose the equipment or item to assign.
  4. Enter end user, department, assignment date, and other assignment details.
  5. Add remarks or supporting details if needed.
  6. Select Save Assignment.

Edit, Reassign, or Unassign

  1. Find the assignment in the table.
  2. Select Edit to update assignment details.
  3. Select Reassign to transfer the item to another end user or department.
  4. Use unassign or archive actions only when the assignment is no longer active.
  5. Confirm the action when the system prompts you.

Upload or View Assignment PDF

  1. Locate the assignment row.
  2. Select Upload File to attach a PDF.
  3. Select the PDF file from your computer.
  4. Confirm upload.
  5. Use the PDF button to view or print the attached document.

8. Other Operations

Subscription

  1. Open Other operations > Subscription > Manage Subscription.
  2. Select New Subscription.
  3. Encode subscription details such as account, provider, period, amount, department, and status.
  4. Save, edit, archive, import, or review archived subscriptions as needed.

Borrowed

  1. Open Other operations > Borrowed > Manage Borrowed.
  2. Add borrowed item details, borrower, department, dates, and remarks.
  3. Save the record and update it when the item is returned or changed.
  4. Archive old borrowed records when no longer active.

Bidding

  1. Open Other operations > Bidding > Manage Bidding.
  2. Create a bidding record and add one or more bidding items.
  3. Fill in bidding dates, department, item details, and remarks.
  4. Use export filters when preparing bidding reports.

Title

  1. Open Other operations > Title > Manage Title.
  2. Add or update title-related records used by the system.
  3. Use archive and import pages where available.

9. Reports and PDFs

Service Report

  1. Open Reports > Service Report.
  2. Create or edit a service report.
  3. Add service items, findings, action taken, personnel, date, and remarks.
  4. Save the report.
  5. Upload a PDF when needed or select PDF to print/export.
  6. Use Service Archive for archived service reports.

Maintenance Report

  1. Open Reports > Maintenance Report.
  2. Add maintenance details such as equipment, performed work, findings, schedule, and personnel.
  3. Save the record.
  4. Use PDF or upload actions for printable documentation.
  5. Archive completed or old maintenance records when appropriate.

Transmittal Report

  1. Open Reports > Transmittal Report.
  2. Select New Transmittal.
  3. Enter transmittal recipient, department, date, item rows, and remarks.
  4. Select Add Row for additional items.
  5. Save and use PDF to print or export.

General Report

  1. Open Reports > General Report.
  2. Choose the module or report tab.
  3. Select Filter & Export.
  4. Set date range, status, department, and other filters as needed.
  5. Choose fields to include and reorder them if supported.
  6. Select Print, PDF, or Excel depending on permission.

10. Masterlists

  1. Open Masterlist > Manage Masterlist.
  2. Select the masterlist category to maintain.
  3. Add a new value using the available form.
  4. Edit values when names, descriptions, or statuses need correction.
  5. Delete or deactivate only when the value is no longer needed and will not affect active records.

Common masterlists may include suppliers, departments, equipment types, statuses, service types, personnel, offices, and other reusable values.

11. Admin, Roles, and Logs

User Administration

  1. Open Account > User Admin or the admin link available to your role.
  2. Review registered users, roles, and account status.
  3. Assign a role to each user.
  4. Review role defaults, then fine-tune permission overrides if needed.
  5. Save changes.

Password Reset Requests

  1. Open the Reset Requests tab in the admin page.
  2. Review the requesting user and request details.
  3. Select Approve to allow the reset or Reject to deny it.
  4. Enter required notes or rejection reason.
  5. Confirm the action.

Activity Logs

  1. Open Account > Logs or Activity Logs.
  2. Filter logs by date, user, module, or activity where available.
  3. Review actions for audit and monitoring purposes.
  4. Use cleanup tools only when authorized by your retention policy.
Admin caution: Permission changes affect what users can see and do. Review role access carefully before saving.

12. Account Settings

Update Account Details

  1. Open Account Details.
  2. Update editable profile fields.
  3. Select Save Account.

Change Password

  1. Open Change Password.
  2. Enter your current password.
  3. Enter and confirm the new password.
  4. Save the change.
  5. Use the new password on your next login.

Logout

  1. Select the logout or power button from the sidebar or account menu.
  2. Wait until the login page appears.
  3. Close the browser tab if using a shared workstation.

13. Best Practices

  • Search before adding a record to avoid duplicates.
  • Use complete descriptions, serial numbers, control numbers, and department names.
  • Upload final signed PDFs when a report or assignment requires attachment.
  • Archive records instead of deleting them when they may still be needed for audit.
  • Keep masterlists clean and standardized.
  • Check reports before printing, exporting, or submitting them outside the office.
  • Use role permissions to limit access to only the features each user needs.

14. Troubleshooting

ProblemWhat to Do
Cannot log inCheck username and password. Use the reset request page if needed.
Module is missingYour role may not have permission. Contact an administrator.
Save button shows an errorReview required fields, duplicate control numbers, invalid dates, and file requirements.
Dropdown value is missingAsk an authorized user to add it in Masterlist.
Upload failedConfirm the file is a supported type, usually PDF, and try again.
Report export is incompleteCheck date range, selected fields, module filter, and your export permission.
Wrong record was archivedOpen the archive page and restore it if restoration is available.
For unresolved issues, record the page name, action attempted, error message, date/time, and username before reporting to the system administrator.
