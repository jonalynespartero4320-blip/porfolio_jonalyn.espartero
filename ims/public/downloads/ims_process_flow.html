IMS Process Flow

Operational sequence from login to record management, reporting, and audit review.

Main Flow

  1. Login: User enters credentials. IMS validates the account and loads role-based access.
  2. Navigate: User selects a module from the sidebar or searches the sidebar for a module name.
  3. Create or update records: User fills required fields, uploads files where needed, and saves the transaction.
  4. Validate: IMS checks required fields, duplicates, dates, file uploads, and permission rules.
  5. Track status: Requests, assignments, reports, and inventory records move through active, completed, rejected, or archived states.
  6. Report: Authorized users filter records and print, export PDF, or export Excel outputs.
  7. Audit: System activity is logged for administrators to review.
