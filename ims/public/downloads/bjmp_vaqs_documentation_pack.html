Combined Process Flow and User Manual

This consolidated document serves as an internal reference for the ID & Queuing System Visitor Admission and Queuing System. It combines the process flow, module guide, role guidance, and user operating instructions into a single formal document for printing and distribution.

1. Process Flow Summary

  1. User authentication through login, registration, and password reset workflow.
  2. Reference preparation through masterlist maintenance.
  3. PDL record management and authorized visitor linking.
  4. Visitor registration with documentary uploads and emergency contact details.
  5. Visitor management for verified records, bans, updates, and routing actions.
  6. ID issuance for verified visitors with QR-secured cards.
  7. Queue admission with one-visit-per-day and occupancy-limit controls.
  8. Queue board and admin monitor for daily live display.
  9. Report generation and export to Excel or print/PDF.
  10. Super admin governance for users, roles, and permissions.

3. Operational Rules

Critical Queue Rules: Each visitor may visit only once per day, only ten visitors may be inside at one time, and the queue board resets daily to current-day activity.
  • Action buttons are permission-controlled.
  • Super admin grants permission before a user can use a function.
  • Admission reports include time in, time out, and hours stayed.
  • ID issuance maintains issuance history for audit and reissue reference.

4. User Operating Guide

4.1 Staff

Staff are responsible for frontline work such as visitor handling, queue intake, and selected issuance operations according to granted permissions.

4.2 Admin

Admins supervise PDL, visitor, reporting, queue, and issuance operations. Their permissions are operational by default and may be extended by super admin.

4.3 Super Admin

Super admin controls platform governance, including users, roles, action permissions, and reset approvals.

5. Recommended Daily Sequence

  1. Confirm masterlist accuracy.
  2. Review or update PDL records.
  3. Register or complete visitor records.
  4. Verify visitor status and issue IDs where needed.
  5. Process queue requests and live admissions.
  6. Monitor queue board and admin monitor.
  7. Generate end-of-day or period-based reports.
