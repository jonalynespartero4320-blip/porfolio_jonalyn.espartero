1. Getting Started

Login

  1. Open the Inventory Management System website in the browser.
  2. Enter your username and password.
  3. Click Login.
  4. If the system asks you to change your password, enter a new password and save it before continuing.

Navigate the System

  1. Use the left sidebar to open modules such as Dashboard, Requests, Equipment, Supplies, Assign, Reports, and Masterlist.
  2. Use the sidebar search box to quickly find a module.
  3. Click nested menu headings to open submodules such as Archive, Import Data, Request Status, and Report Archive.
  4. Use your account menu for My Account, Change Password, Activity Logs, Admin Users, or Logout if available.

Common Buttons

2. Masterlists

Masterlists control the dropdown selections used across the system. Keep these values clean and consistent before encoding transactions.

  1. Open Masterlist > Manage Masterlist.
  2. Select the masterlist tab you need, such as Equipment Status, Description, Brand, Department, End User, Supplier, Complaint, Troubleshoot, or Service Remarks.
  3. Click Add to create a new option.
  4. Enter the exact name or description to be shown in forms.
  5. Click Save.
  6. Use Edit to correct spelling or update an existing option.
Before creating service reports, make sure the complaint, troubleshoot, remarks, department, end user, and equipment status lists are updated.

3. Requests

Equipment Request

  1. Open Request > Equipment > Request Equipment.
  2. Click New Equipment Request.
  3. Select the requesting end user and department.
  4. Add requested equipment or supplies in the item list.
  5. Enter the request purpose, remarks, and required details.
  6. Save the request.
  7. Use View or Edit from the request table when changes are needed.

Service Request

  1. Open Request > Service > Request Service.
  2. Create a new request and fill in the end user, department, concern, and requested service details.
  3. Save the request.
  4. When ready, click the report action to create a service report from the request.

Request Status

  1. Open the corresponding Request Status page if you have management permission.
  2. Add or edit statuses used to monitor request progress.
  3. Use clear status names, such as Pending, Approved, Released, Completed, Cancelled, or Returned.

4. Equipment Management

Add Equipment by Batch

  1. Open Equipment > Manage Equipment.
  2. Click Add Equipment or the batch add button.
  3. Select the supplier.
  4. Enter the Date Delivered. The control number year is based on this date.
  5. Fill in description, brand, serial number, warranty information, delivery status, ETA if still to follow, and remarks.
  6. Leave Control No blank if you want the system to generate it.
  7. Add more rows if the same batch contains multiple equipment items.
  8. Click Save.
FieldUse
Control NoGenerated as IT-YY-#### using the delivered year.
Date DeliveredRequired for batch generation and warranty tracking.
WarrantyUsed to determine warranty status.
Delivery Status and ETAUse ETA when the item is still to follow.

Edit, Archive, and Import

  1. Use the search box or table filters to find the equipment.
  2. Click Edit to update identification, delivery, warranty, status, or remarks.
  3. Click Archive when equipment should no longer appear in the active table.
  4. Open Equipment > Import Data to upload records in the supported template format.

5. Supplies Management

Add Supplies by Batch

  1. Open Supplies > Manage Supplies.
  2. Click Add Supplies.
  3. Select the supplier.
  4. Enter the batch delivered date.
  5. Fill in description, brand, serial number if applicable, status, warranty date, delivery status, ETA, and remarks.
  6. Leave Code blank if you want the system to generate it.
  7. Add additional supply rows for the same batch.
  8. Click Save.
Supply codes are generated as SUP-YY-####. The system checks active and archived supply records before choosing the next number.

View, Edit, Archive, and Import

  1. Search for the supply in the active table.
  2. Use View to check details.
  3. Use Edit to update status, delivery, warranty, supplier, or remarks.
  4. Use Archive to move the supply out of the active table.
  5. Use Import Data for bulk upload when available.

6. Assignment

The assignment module records which equipment or supplies are issued to an end user and department.

  1. Open Assign > Manage Assign.
  2. Click New Assignment.
  3. Select the end user. Confirm the department displayed by the system.
  4. Select the equipment or supplies to assign.
  5. Review the control number, serial number, and status.
  6. Save the assignment.
  7. Use Assignment History to check previous assignment movement.
When an item is assigned, its assigned status is reflected in the related equipment or supplies list.

7. Service Report

Create a Service Report

  1. Open Reports > Service Report.
  2. Click New Service Report.
  3. Select the end user. The department will be filled automatically when available.
  4. Select an optional employee designation. If designation is available, it is used in the PDF; otherwise the department is displayed.
  5. Fill in travel date, vicinity, distance, departure time, and arrival time.
  6. Add complaint and troubleshooting details from the dropdown lists.
  7. Add remarks and pullout details when applicable.
  8. Select the attending technician and confirm the technician designation.
  9. Set the report date and time.
  10. Attach a PDF if supporting documents are required.
  11. Click Save Service Report.

Add Equipment, Supplies, Subscription, or Other Items

  1. Use the equipment picker to add existing assigned or inventory equipment.
  2. Use Add New Equipment if the item is not yet in the equipment table.
  3. For new equipment, enter Date Delivered. If Control No is blank, the system generates the control number from the delivered year.
  4. Use the supplies picker or Add New Supply to connect supplies.
  5. For new supplies, leave Supply Code blank if the system should generate the next supply code.
  6. Add subscription or other/as-is items when the item does not belong to equipment or supplies.
  7. Review status, serial number, warranty date, warranty remarks, and service remarks before saving.

Print or Save PDF

  1. Find the saved service report in the table.
  2. Click PDF.
  3. The PDF opens in the browser PDF tab.
  4. Use the browser print or download button to print or save the report.

8. Maintenance Report

  1. Open Reports > Maintenance Report.
  2. Click New Maintenance Report.
  3. Select the end user and department.
  4. Optionally select a designation. The PDF uses designation when available; otherwise it uses department.
  5. Enter the maintenance date, equipment details, work performed, technician, remarks, and item status.
  6. Save the report.
  7. Use PDF to open the print-ready maintenance report.
  8. Use Archive to move old records to the maintenance archive.

9. Transmittal Report

  1. Open Reports > Transmittal Report.
  2. Click New Transmittal.
  3. Select the receiving end user, department, and optional designation.
  4. Select equipment and supplies from the item pickers.
  5. Add manual entries for items that are not recorded in inventory.
  6. Review all selected and manual items before saving.
  7. Click Save.
  8. Use the row toggle or View to confirm that selected equipment, supplies, and manual entries are listed under the transmittal.
  9. Use Edit when item selections or manual entries need to be updated.
  10. Use PDF to open the print-ready transmittal form.

10. Archives, Reports, and Administration

Archives

  1. Open the archive page for the module, such as Equipment Archive, Supplies Archive, Service Archive, Maintenance Archive, or Transmittal Archive.
  2. Search for the archived record.
  3. Use View to inspect details.
  4. Use Restore if the record must return to active records.

General Reports

  1. Open Reports > General Report.
  2. Select the module or report category.
  3. Apply date, status, department, or keyword filters as needed.
  4. Use export or print actions to generate the required report output.

Admin Users and Permissions

  1. Open Admin Users from the account menu if you have permission.
  2. Create or edit user accounts.
  3. Assign roles and module permissions based on the user responsibility.
  4. Save changes and ask the user to log out and log in again if permissions changed.

Activity Logs

  1. Open Activity Logs from the account menu.
  2. Search or filter logs to review user actions.
  3. Use logs when auditing changes, archiving, restoring, or troubleshooting data updates.

11. Troubleshooting Guide

IssueWhat to Check
Menu is missingYour account may not have permission for that module. Ask the administrator to check your role.
Dropdown has no optionOpen Masterlist and add the missing department, end user, status, description, brand, supplier, complaint, troubleshoot, or remarks value.
Control number is not generatedFor equipment, make sure Date Delivered is filled. For supplies, leave Code blank if auto-generation is needed.
PDF logo or format issueUse the PDF action from the system and print from the browser PDF tab. Confirm image files exist under public assets.
Selected transmittal items are missingOpen Edit and confirm equipment/supply selections are still listed before saving.
Duplicate entry errorThe same item may already be assigned or saved in a unique field. Search active and archive records before saving again.
Cannot restore archived recordAn active record may already use the same code or control number. Resolve the duplicate first.
Recommended daily practice: update masterlists first, encode inventory with supplier and delivery details, assign items to end users, then create service, maintenance, and transmittal reports from accurate records.
