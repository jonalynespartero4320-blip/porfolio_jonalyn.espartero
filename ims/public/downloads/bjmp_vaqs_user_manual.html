User Manual

Document Type: Operations and User Guide

This manual provides practical instructions for using the ID & Queuing System. It is intended for staff, administrators, and supervisory personnel who are responsible for visitor processing, queue operations, reporting, and system governance.

1. Accessing the System

1.1 Login Procedure

  1. Open the ID & Queuing System login page.
  2. Enter the assigned username or email address.
  3. Enter the correct password.
  4. Select Sign In to enter the system.

1.2 Forgot Password Procedure

  1. Open the Forgot Password page.
  2. Enter the username assigned to the account.
  3. Submit the password reset request.
  4. Wait for administrator approval and the issuance of a replacement password.

3. Daily Operating Procedure

3.1 Preparing Records

  1. Review case, court, and dorm masterlists to ensure they are updated.
  2. Create or update PDL records as required.
  3. Confirm authorized visitors linked to the selected PDL.

3.2 Registering a Visitor

  1. Open the Visitor Registration module.
  2. Select the relevant PDL record.
  3. Enter the visitor's personal information.
  4. Upload the visitor photo and required documentary files.
  5. Submit the registration.

3.3 Managing a Verified Visitor

  1. Open the Visitor Management module.
  2. Search and open the verified visitor record.
  3. Review linked PDL data, issued ID status, and uploaded files.
  4. If necessary, update the photo or documentary requirement file.
  5. Apply a ban or lift a ban when authorized.

3.4 Issuing an ID

  1. Open the ID Issuance module.
  2. Select the relevant PDL.
  3. Choose the verified visitor for issuance.
  4. Select Issue or Re-Issue.
  5. Open the generated card and print or export it.

3.5 Queue Admission

  1. Open the Queue module.
  2. Scan the visitor QR or search manually.
  3. Review the visitor details shown on screen.
  4. Select Put in Queue and encode the presented ID details.
  5. Accept or reject the queue request as appropriate.
  6. Record Time Out once the visit is completed.
Important: The system allows only one visit per visitor per day and only ten visitors inside the facility at one time.

4. Reporting Procedure

  1. Open the Reports module.
  2. Select the report source: Admissions, Registrations, or ID Issuance.
  3. Select the desired period type: Daily, Monthly, Yearly, or Custom Range.
  4. Apply the filters.
  5. Review the report table, including time in, time out, and hours stayed for admission reports.
  6. Export to Excel or open the print/PDF layout as required.

5. Role Responsibilities

6. Permission Guidance

Action buttons and backend functions are permission-controlled. Users must be granted the required permission before they can open or use a function. Super admin is responsible for assigning these permissions in the Manage Users module.
